## 1xPDF làm được gì

- **Sửa chữ PDF giữ nguyên font**: dùng lại font nhúng trong PDF. Nếu font thiếu ký tự cần gõ, 1xPDF từ chối và cho bạn thả file font vào, không lặng lẽ đổi sang font khác.
- **Giữ bố cục**: chữ mới đứng đúng vị trí, giữ căn trái, căn giữa, căn phải. Dời được cụm chữ, logo, hình ảnh bằng chuột hoặc phím mũi tên.
- **Không tự đổi metadata**: Info, XMP và ID của file giữ nguyên; chỉ đổi khi bạn tự sửa và duyệt trong bảng Meta.
- **Hoàn tác, làm lại** từng lần sửa.
- **Từ chối chỗ sửa không an toàn** kèm lý do (ví dụ PDF dùng bảng mã cũ như TCVN3, VNI), thay vì xuất ra một file trông giống mà sai.

## English

**1xPDF** edits the text inside PDF files while keeping the embedded fonts, font size, colour and layout. Click a line, retype, press Enter. It never swaps fonts silently, and it leaves the file's metadata (Info, XMP, ID) untouched unless you approve a change. Runs as a Mac app (local, 7-day trial) or [online in the browser](https://xuanhieu.org/tool/pdf). Product page and pricing: [1xag.com/pdf/en](https://1xag.com/pdf/en).
